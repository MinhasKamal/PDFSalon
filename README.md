## Supported Functions
- [X] Insert Text: Change text color, font type, and font size
- [X] Insert Image
- [X] Insert Symbol: Tick (✓) and cross (☓), also change their size and color
- [X] Rearrange pages
- [X] Merge multiple files
- [X] Delete pages
- [X] Rotate pages
- [X] Convert images to PDF
- [X] Privacy: Files never leaves the device. So, it is private and free for all kinds of usage.
